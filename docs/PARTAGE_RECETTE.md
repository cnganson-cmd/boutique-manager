# Partager la recette aux testeurs

## Adresse à communiquer

`https://cnganson-cmd.github.io/boutique-manager/test.html`

Cette adresse utilise uniquement la base `boutique-test`. Les saisies de recette
ne modifient donc pas l'environnement DEV.

## Avant l'envoi

L'Administrateur crée une fiche par testeur, renseigne son adresse e-mail, lui
attribue son rôle et son site, puis lui envoie une invitation. Ne jamais partager
un compte commun : l'historique doit pouvoir identifier la personne qui a réalisé
chaque transaction.

## Installation

### Android (Chrome)

1. Ouvrir le lien de recette dans Chrome.
2. Ouvrir le menu `⋮`.
3. Choisir **Installer l'application** ou **Ajouter à l'écran d'accueil**.
4. Ouvrir **SAM Recette** depuis l'écran d'accueil.

### iPhone ou iPad (Safari)

1. Ouvrir le lien dans Safari.
2. Appuyer sur **Partager**.
3. Choisir **Sur l'écran d'accueil**, puis **Ajouter**.

### Ordinateur (Chrome ou Edge)

1. Ouvrir le lien de recette.
2. Cliquer sur l'icône d'installation dans la barre d'adresse, ou utiliser le
   menu du navigateur puis **Installer Parfumerie SAM · Recette**.

## Connexion et réseau

- Le premier chargement et les opérations métier nécessitent Internet.
- Le shell de l'application est ensuite mis en cache pour accélérer les
  ouvertures sur une connexion lente.
- Les stocks et les montants restent lus en ligne afin de ne jamais afficher une
  valeur périmée comme si elle était actuelle.
- Pour un incident, noter le profil, la page, l'action, l'heure et joindre une
  capture d'écran sans mot de passe.

## Rappel visuel

L'application installée porte le nom **SAM Recette**. L'application DEV porte le
nom **SAM Manager**. Un testeur doit toujours utiliser **SAM Recette**.
